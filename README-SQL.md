## 📋 الخطوات:

### 1️⃣ افتحي Supabase Dashboard
اذهبي إلى: https://supabase.com/dashboard

### 2️⃣ اختاري مشروعك
اضغطي على مشروع **أثر**

### 3️⃣ افتحي SQL Editor
من القائمة الجانبية → **SQL Editor**

### 4️⃣ انسخي ملف START-HERE.sql
- افتحي ملف `START-HERE.sql`
- اضغطي **Ctrl+A** (تحديد الكل)
- اضغطي **Ctrl+C** (نسخ)

### 5️⃣ الصقي في Supabase
- ارجعي لـ Supabase SQL Editor
- الصقي الكود (Ctrl+V)
- اضغطي **RUN** أو **F5**

### 6️⃣ انتظري
راح تشوفين رسائل في الأسفل تقول:
```

🔓 تعطيل Row Level Security...
📁 إعداد Storage Bucket...
🎉 تم إكمال الإعداد بنجاح!
```

## 📊 ماذا يفعل هذا الملف؟

1. ✅ يضيف عمود `teacher_type` (نطق / تربية خاصة)
2. ✅ ينشئ 11 جدول جديد:
   - الحضور والغياب
   - متابعة الطالبة (بأهداف متعددة)
   - اختبار الذاكرة السمعية
   - التقرير المبدئي
   - موافقة ولي الأمر
   - ملاحظات الطالبة
   - البيانات الأولية (مشتركة)
   - التشخيص الطبي (PDF)
   - الخطة الفردية IEP
   - متابعة الجلسات
   - رسائل ولي الأمر
3. ✅ يعطّل RLS (للتسهيل في الاختبار)
4. ✅ ينشئ Storage Bucket للملفات
